# Experiment Protocol

## Primary research question
Can dataset meta-features predict whether GBDT or DNN will perform better on an unseen tabular dataset?

## Secondary questions
- Which meta-features are consistently useful?
- Does a recommender trained on general datasets transfer to clinical tabular data?

## Decisions to lock before large runs
- Dataset inclusion/exclusion criteria
- Classification vs regression scope
- Exact GBDT and DNN membership
- Preprocessing regime
- Equal HPO budget
- Winner-family rule
- Held-out-dataset evaluation protocol
